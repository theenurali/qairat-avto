# ADS Exam Prep — подготовка к экзамену Algorithms & Data Structures

Интерактивная платформа к экзамену 29 ноября 2026 (60 минут): Hash Tables, Rabin-Karp, KMP, Graph Representation, BFS, DFS, Topological Sort.

## Запуск

```powershell
cd ads-prep
npm install      # один раз
npm run dev      # http://localhost:5188
```

Production-сборка: `npm run build`, затем `npm run preview`.
Публикация на GitHub Pages: `npm run build:pages` — собирает сайт в папку `../ads` (https://theenurali.github.io/qairat-avto/ads/), затем закоммитьте и запушьте её.
Тесты (алгоритмы, все задания, контрпримеры, mock exams): `npm test`.

## Что внутри

| Раздел | Содержимое |
|---|---|
| Dashboard | обратный отсчёт, общий прогресс, решённые задачи, слабые темы, Continue Learning |
| Learning Path | 4 модуля, 12 уроков: теория, аналогии, визуализаторы, пошаговые примеры, Python-код с разбором, сложность, ошибки, самопроверка, практика, мини-экзамен |
| Tracing Practice | 68 заданий (≥15 на модуль), проверка с указанием позиции ошибки и пошаговым решением |
| Counterexamples | 26 задач с кодом с ошибкой; сайт запускает код с ошибкой и правильный код на ваших данных |
| Theory Test | 146 вопросов multiple choice с объяснениями, фильтры, режим «только ошибки» |
| Open Questions | 33 вопроса EN + RU, образцовый ответ, чек-лист ключевых пунктов |
| Complexity | таблица Best/Average/Worst/Space + как определять Big O, упражнения |
| Mock Exam | 3 варианта по 60 минут, все 4 формата, разбор и слабые темы |

Весь код на сайте есть в двух вариантах — **Python и C++**: переключатель в боковом меню (и на каждом блоке кода), выбор запоминается. Все C++-фрагменты проверяются компиляцией `g++ -std=c++17` в тесте `src/tests/cpp.test.ts`.

Прогресс хранится в `localStorage` браузера (ключ `ads-prep-progress-v1`) и сохраняется между перезагрузками.

Ответы в Tracing и проверки контрпримеров вычисляются настоящими реализациями алгоритмов (`src/lib/algorithms`), а не захардкожены. Открытые вопросы проверяются самооценкой по ключевым пунктам; автоподсказка по ключевым словам — только ориентир.
